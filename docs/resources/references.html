Public evidence corpora

NIST CFReDS

The Tier 2 anchor. The Data Leakage Case supplies NTFS, exFAT, FAT32 and UDF/optical evidence from a single scenario, in both E01 and raw, with published hashes — the two file systems our own lab cannot produce. A US Government work in the public domain, so classroom use is unrestricted; we link rather than rehost by choice.

cfreds.nist.gov Tier 2

Practical notes before you download

The images live on the archive host rather than the portal, the PC image is several gigabytes, and the raw variants are 7-Zip split archives (.7z.001) — not split raw segments. Extract them before adding them to a tool, or the tool will read one fragment and tell you nothing is there.

Tool notes that change how we teach

KAPE licensing

As of 1 January 2026, KAPE is no longer available for commercial use — that is, on a third-party network or as part of a paid engagement. Classroom and educational use remains free, so we still teach it, and every KAPE step in this course is paired with a free standalone alternative so you can do the same work on Monday. The limit is stated in the session, not left to be discovered mid-engagement.

Tool versions and artifact paths are re-checked when each session is built, and the version used is written into that session's lab. A command that worked in a course recorded two years ago is not evidence that it works now.
