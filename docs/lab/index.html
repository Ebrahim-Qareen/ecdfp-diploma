Before your first session

Setup
  • 250 GB free on the host, and VMware Workstation installed.
  • FOR-WS01 ships pre-built — a clean Windows with no tools. You install the tool set in S1 and take the CLEAN-TOOLS snapshot yourself. Building the workstation is not a use of class time; using it is.
  • The session's evidence downloaded and hash-verified before class.

The full build guide is live. The step-by-step build of FOR-WS01 — the Windows 11 VM, the tool set installed session by session, verification and snapshots — is at Workstation setup →. Machine specs, the host requirement and the snapshot policy above are settled.

Snapshot policy

One snapshot per session on FOR-WS01, taken before you touch evidence.

  • CLEAN-TOOLS — taken in S1 once the tool set is installed and verified. Never delete this one. Every later session is recoverable from it.
  • S0N-START — taken at the start of each session, before any evidence is mounted.
  • EVI-SRC01 is snapshotted by the instructor before staging, so the compromise can be re-run.
Caveat

A snapshot is not a forensic copy and never appears in a chain-of-custody form. It protects your workstation, not the evidence — the evidence is protected by hashes and by working only on a copy.
