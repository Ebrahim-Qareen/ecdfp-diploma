T18 · EVIDENCE OF EXECUTION · 40 MIN

Three artifacts, three different claims تلات آثار، و كل واحد بيدّعي حاجة مختلفة

Prefetch, Amcache and ShimCache are all called “evidence of execution.” Only one of them actually is. Getting this wrong is the single most common mistake in a Windows examination, and it is the mistake that puts a wrong name in a report. التلاتة بيتقال عليهم "دليل تشغيل"، بس واحد بس فيهم اللي فعلاً كده. الغلطة دي أشهر غلطة في فحص ويندوز — و هي اللي بتحط اسم غلط في التقرير.

FIG T18-1 · WHAT EACH ARTIFACT ACTUALLY PROVES 1 / 3 · PREFETCH2 / 3 · AMCACHE3 / 3 · SHIMCACHE
Prefetch C:\Windows\Prefetch\*.pf PROVES EXECUTION
The program ran. The file records run count and the last eight run times. البرنامج اشتغل فعلاً. الملف بيسجّل عدد المرات و آخر ٨ مواعيد تشغيل.
Amcache C:\Windows\AppCompat\Programs\Amcache.hve PRESENCE ONLY
The file existed on this system, with its SHA-1 and compile time. It does not say the program ran. الملف كان موجود على الجهاز، و معاه الـ SHA-1 و وقت الـ compile. لكنه مش بيقول إنه اشتغل.
ShimCache SYSTEM\CurrentControlSet\Control\Session Manager\AppCompatCache PRESENCE ONLY
Windows looked at the file. That is all. An entry here is created by a directory listing as readily as by an execution. ويندوز بصّ على الملف. بس كده. الإدخال هنا ممكن يتعمل من مجرد فتح الفولدر زي ما بيتعمل من التشغيل.
Prefetch is the only one of the three that answers “did it run?” Amcache answers “was it here?” — a different question with a similar-looking answer. ShimCache answers “did Windows see it?” — and analysts read it as execution every day.
